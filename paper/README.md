# Manuscript Source and Build

This directory contains the LaTeX source for the article **"Quantum Mpemba Effect in Disordered Lattices"** formatted with the Springer Nature `sn-jnl` template.

## Contents

- `main.tex` — Main LaTeX manuscript.
- `refs.bib` — BibTeX reference database.
- `sn-jnl.cls`, `sn-*.bst` — Springer Nature template class and bibliography styles.
- `figures/` — Vector PDF figures generated by the scripts in `scripts/`.
- `main.pdf` — Precompiled article PDF.

## Compilation

To compile the manuscript locally using pdfLaTeX and BibTeX:

```bash
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```
