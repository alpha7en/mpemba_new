## 2026-07-19 — Блок A: точные спектральные проекции (замечание CF-1)

**Проблема (подтверждена):** попарная формула c_k = ⟨w_k|ρ⟩/⟨w_k|v_k⟩ некорректна внутри
вырожденных мультиплетов регулярной решётки (LAPACK не выдаёт биортогонально спаренные
лево/правые векторы). Ошибка реконструкции для «Coherent diag.» достигала ~1e3 %.

**Изменено:**
- `src/qdyn_research/metrics.py` — ДОБАВЛЕНЫ (аддитивно, легаси не тронуто):
  `factor_mode_basis` (LU от V), `project_rho_on_modes_exact` (решение V·c = vec(ρ)
  с ≤2 шагами итерационного уточнения; возвращает невязку реконструкции).
- `scripts/fig2_projection_bars_and_modes.py` — v2: точные проекции; кластеризация
  спектра на вырожденные мультиплеты (tol 1e-6 → 2613 кластеров); бары = базис-
  инвариантные веса мультиплетов ||V_μ c_μ||²; жёсткий контроль невязки (>1e-6 → отказ).
- `scripts/precalc/fig2_projections_exact.npz` — новый кэш (коэффициенты, невязки,
  спектр, кластеры, инвариантные веса). Легаси-кэш `fig2_projections.npz` сохранён
  для сравнения.
- `paper/figures/new_tabled_10x10_bar_chart_log_ENG_new_8STATES.pdf` — перегенерирован.
- `paper/main.tex` — 3 правки (одобрены): стр. ~271 честное описание нормировки
  (валидность попарной формулы + точное решение + контроль ≤1e-10); стр. ~273 описание
  W_{k'} (веса мультиплетов, базис-инвариантность); подпись Fig. 2 (W_k → W_{k'}).

**Результаты пересчёта:** невязки 7 состояний ~1e-13–1e-15; «Coherent diag.» 5.7e-11
(max|c| = 2.45e5 — почти-дефектный квадруплет, потолок ε·||c||). Веса 7 некогерентных
состояний практически не изменились (TV-расстояние 0.00–0.10); «Coherent diag.»
изменился на 92 % (TV=0.92) — старая панель была артефактом.

**Не изменилось (контроль):** Fig. 3 (пересечение 2×5) не зависит от разложения —
считается прямым интегрированием ODE; проверено по кэшу fig3: в окне t≤4 существует
ровно одна пересекающаяся пара (Coherent diag. × Opp. corners, t*=2.09). Селективность
7 смесей подтверждена точной математикой. Алгоритмическая секция и бенчмарк не затронуты.

**Отложено:** формулировка зелёного абзаца стр. ~279 («symmetry selection rules») —
ждёт одобрения пользователя (пункт 3).
